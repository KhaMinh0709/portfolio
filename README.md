Portfolio Website

📖 Giới thiệu

Portfolio cá nhân được xây dựng để giới thiệu kỹ năng, dự án và thông tin liên hệ. Dự án này thể hiện khả năng sử dụng ReactJS và TailwindCSS để phát triển giao diện web hiện đại, tối ưu hiển thị trên mọi thiết bị.

🛠️ Công nghệ sử dụng
	•	ReactJS – xây dựng component UI.
	•	TailwindCSS – thiết kế giao diện nhanh chóng và responsive.
	•	Vite – công cụ build & dev server tốc độ cao.
	•	EmailJS – tích hợp form liên hệ trực tiếp qua email.
	•	Framer Motion – tạo hiệu ứng animation mượt mà.
	•	Vercel – triển khai và hosting website.

✨ Chức năng chính
	•	Trang giới thiệu cá nhân (About Me).
	•	Liệt kê kỹ năng & dự án (Skills & Projects).
	•	Form liên hệ tích hợp EmailJS (Contact).
	•	Thiết kế responsive, hoạt động tốt trên mobile & desktop.
	•	Animation sinh động với Framer Motion.
